# Política de segurança

## Como reportar uma vulnerabilidade

Escreva para **arandurape@internetbitabit.com.br** com o assunto "Segurança". Não abra uma *issue* nem uma discussão pública antes de receber resposta.
Inclua, se possível:

- o que você encontrou e onde (endereço, rota da API ou arquivo);
- como reproduzir, sem acessar dados de outras pessoas além do mínimo necessário para demonstrar;
- o impacto que você enxerga.

Respondemos para confirmar o recebimento e informar o andamento. Pedimos um prazo razoável para corrigir antes de qualquer divulgação, e creditamos
quem reportou, se desejar.

## O que está no escopo

O código deste repositório e a instância oficial do Arandurapé: API, servidor MCP, interface web, autenticação e controle de acesso.

Fora do escopo: ataques de negação de serviço, testes automatizados em volume contra a instância oficial, engenharia social e as fontes de dados de
terceiros (reporte a elas).

## Dados pessoais

Contatos e dados de pessoa física não são públicos no Arandurapé. Se você encontrar um caminho que os exponha (página, API, MCP ou arquivo), trate como
vulnerabilidade e reporte por este canal.

## Versões suportadas

Apenas a versão em produção (indicada no rodapé do site e no arquivo `VERSION`) recebe correções de segurança.
