# Logotipo do Arandurapé

Logotipo do **software**. Não é a marca de nenhuma instância: o site que roda o Arandurapé usa a sua, em `instancia/marca/`
(fora do git, ver `instancia/README.md`), ou o "A" padrão de `frontend/public/`. Esta pasta não entra na imagem do frontend.

| Arquivo | Uso |
|---|---|
| `arandurape-logo.svg` | Globo e nome; topo do README |
| `arandurape-simbolo.svg` | Só o globo |
| `arandurape-previa-social.png` | Prévia social do GitHub (1280×640), enviada à mão em Settings → General → Social preview |
| `gerar_arandurape.py` | Gera os dois SVGs (Natural Earth 1:110m, domínio público; texto em contorno da Lato Semibold, SIL OFL) |
| `gerar_previa_social.py` | Monta a prévia social a partir dos SVGs (precisa do `rsvg-convert`) |

O globo é uma projeção ortográfica com o sul para cima, centrada em 14° S, 53° O; a rota dourada é simbólica, não geográfica.
